# Tokyo Market

Tokyo Market is a multi-vendor e-commerce platform designed for the Japanese market.

The platform allows multiple sellers to create and manage stores, publish products, control inventory, and process customer orders through one marketplace.

## Project Goal

The goal of this project is to experience and demonstrate a complete software development lifecycle, including:

- Requirement analysis
- System design
- Database design
- REST API development
- Frontend development
- Security
- Testing
- Docker deployment
- CI/CD
- Technical documentation
